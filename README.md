# Shangri-lá Residencial para Idosos

Este projeto é uma **Landing Page profissional** desenvolvida em **Next.js 15.1**, com **React 19**, **Tailwind CSS**, animações com **Framer Motion** e envio de formulários via **EmailJS**. O objetivo é apresentar de forma acolhedora e responsiva a estrutura, os serviços e os diferenciais da **Casa de Repouso Shangri-lá**, destacando suas duas unidades modernas, equipe multidisciplinar e filosofia de cuidado humanizado.

---

## 📌 **Recursos do Projeto**

- **Framework:** Next.js 15.1 (React 19)
- **Estilização:** Tailwind CSS
- **Animações:** Framer Motion
- **Ícones:** React Icons
- **Envio de Formulários:** EmailJS
- **Estrutura Semântica:** SEO otimizado
- **Responsividade:** 100% responsivo para dispositivos móveis e desktops

🌐 Variáveis de Ambiente
Para envio de emails pelo EmailJS, configure suas variáveis de ambiente no arquivo .env.local:

env

NEXT_PUBLIC_EMAILJS_USER_ID=YOUR_USER_ID
NEXT_PUBLIC_EMAILJS_SERVICE_ID=YOUR_SERVICE_ID
NEXT_PUBLIC_EMAILJS_TEMPLATE_ID=YOUR_TEMPLATE_ID
Substitua pelos valores gerados no seu Dashboard EmailJS.

✅ Principais Seções
Cabeçalho: Imagem de capa e introdução

Serviços: Cards informativos com ícones, textos e botões

Galeria: Galeria de imagens das unidades

Quem Somos: Texto institucional detalhado

Endereços: Localização e estrutura das unidades

Contato: Formulário de agendamento de visita com envio via EmailJS

Rodapé: Informações de contato adicionais

💡 Como Personalizar
Edite os campos em components/fields/FieldsInfo.ts para atualizar textos e ícones.

Substitua imagens em public/ ou configure novas em FieldsImages.ts.

Configure o envio de emails no componente CardContact usando EmailJS.

Ajuste as cores e temas no tailwind.config.js.

📣 Deploy
Este projeto é pronto para deploy no Vercel, Netlify ou qualquer provedor compatível com Next.js.

Para Vercel:

Faça login em https://vercel.com/

Conecte seu repositório GitHub

Configure suas variáveis de ambiente no painel do projeto

Clique em Deploy
